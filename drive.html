What minting does
  • Each file gets a private record on Bitcoin: its name, type, size, sha256 fingerprint, date and (for Drive) its link, locked with your wallet’s keys. Only you can open it.
  • The fingerprint proves later that a file is the same one, byte for byte. The file itself stays where it is.
  • 1p per file plus a small network fee, shown above before anything happens. Your wallet asks once per batch.
  • You can make any one record public later. It then shows on Browse and your page.
  • Keeping the whole file on chain, encrypted, is Coming. Its cost is shown beside the record cost so you can see it first.
